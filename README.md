# CodeAlpha Object Detection and Tracking

## Project Overview
This project was developed as part of my CodeAlpha Artificial Intelligence Internship. It demonstrates object detection in video using a pre-trained YOLO model.

## Objectives
- Detect objects in video frames.
- Identify objects using labels and bounding boxes.
- Process video frames and generate an output video.

## Technologies Used
- Python
- Google Colab
- Ultralytics YOLO
- OpenCV

## How It Works
1. Install the required Python libraries.
2. Load the pre-trained YOLO model.
3. Read and process the input video frame by frame.
4. Detect objects and display bounding boxes and labels.
5. Save the processed video in the output folder.

## Output
The processed output video is generated in the `runs/detect/predict` folder in Google Colab.

The output video is included in this repository for demonstration, if uploaded successfully.

## Tools and Environment
The project was developed and tested using Google Colab.
